# Seminar guide: Reconstructing Implicit Scientific Knowledge (Wang et al., 2026)

A static, self-contained website. No build step, no CDN: fonts, KaTeX, scripts, styles and figures are all in this folder.

## Deploy on GitHub Pages

1. Create a repository and upload the **contents** of this folder to its root (so `index.html` sits at the top level).
2. Settings → Pages → Build and deployment → Source: *Deploy from a branch* → Branch: `main`, folder `/ (root)` → Save.
3. After a minute the site is live at `https://<user>.github.io/<repo>/`.

Independent study guide, not affiliated with the authors; all figures are redrawn originals.
Licences for KaTeX and the bundled fonts are in `assets/vendor/katex/LICENSE.txt` and `assets/fonts/LICENSES.txt`.
