Improving the methodology

The same critique, organised by stage of the study, so it can be read as a revised protocol.

If I could change only three things. First, report the attribution families (outcomes by model, workflow and paper, with run counts), because that is the experiment that would separate agent from source. Second, test linking directly by altering a stated correction in a copy of a paper. Third, pre-state a match tolerance and complete the missing artefacts, so that the central claims can be checked by someone else.

Bottom line

The paper’s strongest contribution is a design: enumerate every plausible path, keep the published target out of sight, run them all and report the spread. That design supports one firm conclusion, that a matching number is weak evidence of reconstructed reasoning.

The weaker step is from that conclusion to claims about agents and papers in general. The corpus is small and from one field, the audit blends source gaps with reading errors, and the mechanism it proposes rests on one case. None of this makes the framing less useful; it means the next study should be judged by the controls listed above.
